Airbnb Clone API
Running

Spring Boot backend API for the Airbnb clone project. Authentication via Auth0 is required for most endpoints. Below are the public endpoints.

Public Endpoints

GET/api/tenant-listing/get-all-by-category?category=ALL
GET/api/tenant-listing/get-one?publicId=<uuid>
POST/api/tenant-listing/search
GET/api/booking/check-availability
GET/assets/countries.json

Frontend is a separate Angular project.
